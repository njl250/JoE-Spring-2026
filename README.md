# Green Bond Adoption and Renewable Energy Growth

Replication repository for state-level panel analysis (2010–2024, $N=48, T=15$).

> **Status — Active Project (Fall 2026):** This repository is actively being maintained. The core dataset (`panel.csv`) and replication scripts (`JoE_Stata.do`) corresponding to the current writing sample remain fully stable and functional.

## Context & Authorship
This repository contains data and code developed for the Case Western Reserve University Journal of Economics. The core research proposal, data cleaning pipeline, and empirical infrastructure were developed as a joint project. The individual write-ups, model extensions, and analytical interpretations in the associated writing sample reflect independent analysis.

## Repository Content
* `panel.csv`: Primary balanced state-year panel dataset (2010–2024).
* `JoE_Stata.do`: Econometric scripts for TWFE models, controls, and interaction terms.
* `Green Bonds EDA.Rmd`: Data processing and EDA scripts for all variables.
