# Green Bond Adoption and Renewable Energy Growth

Replication repository for state-level panel analysis (2010–2024, $N=48, T=15$).

> **Status — Active Project (Fall 2026):** This repository is actively being maintained. The core dataset (`panel_improved.csv`) and replication scripts (`JoE_Final_Analysis.do`) corresponding to the current writing sample remain fully stable and functional.

## Context & Authorship
This repository contains data and code developed for the Case Western Reserve University Journal of Economics. The core research proposal, data cleaning pipeline, and empirical infrastructure were developed as a joint project. The individual write-ups, model extensions, and analytical interpretations in the associated writing sample reflect independent analysis.

## Repository Content
* `panel_improved.csv`: Primary balanced state-year panel dataset (2010–2024).
* `JoE_Final_Analysis.do`: Econometric scripts for TWFE, CSDiD, and HonestDiD models.
* `Green Bonds EDA_improved.Rmd`: Data processing and EDA scripts for all variables.
