# Green Bond Adoption and Renewable Energy Growth

Replication repository for state-level panel analysis (2010–2024, N=48, T=15).

## Context & Authorship
This repository contains data and code developed for the *CWRU Journal of Economics*. The core research proposal, data cleaning pipeline, and empirical infrastructure were developed as a joint project. The individual write-ups, model extensions, and analytical interpretations in the associated writing sample reflect independent analysis.

## Repository Content
* `panel.csv`: Primary balanced state-year panel dataset (2010–2024).
* `JoE_Stata.do`: Econometric scripts for TWFE models, controls, and interaction terms.
* `Green Bonds EDA.Rmd`: Data processing and EDA scripts for all variables.
